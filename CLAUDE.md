## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default canonical labels, mapped onto this repo's existing `bug`/`enhancement`/`wontfix` labels plus four new state labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root (created lazily by `/domain-modeling` as terms/decisions actually get resolved). See `docs/agents/domain.md`.
